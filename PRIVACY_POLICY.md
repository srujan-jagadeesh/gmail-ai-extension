# Privacy Policy for Srujan Mail AI Tool

Srujan Mail AI Tool operates as an open-source browser extension. This Privacy Policy outlines how user data is handled.

## 1. Data Collection & Processing
* **API Key Storage**: Your Gemini API key is stored locally on your device using Chrome's local storage API (`chrome.storage.local`). It is never sent to any developer-owned or third-party servers.
* **Email Content**: Email thread contents are parsed strictly locally within your browser to generate reply context. This data is sent directly to Google's Gemini API over secure HTTPS to generate responses and is not logged, stored, or retained by this extension.

## 2. Data Sharing & Third Parties
* We do not sell, rent, trade, or transfer any user data to third parties.
* All AI requests are transmitted directly to the official Google Gemini API endpoint.

## 3. Contact & Support
If you have questions regarding this privacy policy, you can open an issue on the project's GitHub repository: https://github.com/srujan-jagadeesh/gmail-ai-extension
